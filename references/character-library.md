# 一朵小可爱 · 角色灵感库 (Character Library)

> 这份库不是"必须照着画"的清单，而是一份**候选菜单 + 审美判断依据**。
> 用法只有一条铁律：**先看云已有的形状最像谁，再从库里挑最贴合的那个角色**。
> 是"云像什么 → 选谁"，绝不是"想画谁 → 把云凑成谁"。云没有的部件一律不画。

## 一、怎么用这份库（判断顺序）

1. **看轮廓走向**：云是横长、竖高、圆团、还是有明显的凸起/尾巴/头颈方向？
2. **在库里找形状匹配**：哪个动物的典型剪影和这朵云最接近？（横长→猫/柯基/水豚；圆团→仓鼠/团子熊/河豚；竖高→企鹅/小熊坐姿；带尖角→兔耳/狐狸/小鸟）
3. **选角度和姿态**：顺着云的朝向选正脸/侧脸/回头，顺着云的团块选趴/坐/探头。
4. **配一个情绪**：默认呆萌治愈；云的明暗和形态本身在暗示什么情绪就顺着来。
5. **宁可少做**：匹配度不足 60% 就退回轻表情模式（两眼一嘴），不硬凑。

## 二、角色库（按云形分组，越靠前越百搭出片）

### A. 横长形的云 → 适合"趴着/横躺"的角色
- **猫**（最百搭：圆脸、三角耳、可正可侧可回头）
- **柯基 / 腊肠犬**（身子长，横云天生适合）
- **水豚**（钝感治愈天花板，横躺、泡温泉感）
- **鲸鱼 / 海豚**（横云 + 一个小水花，梦幻）
- **鳄鱼 / 恐龙宝宝**（横长带背脊起伏的云）

### B. 圆团形的云 → 适合"圆滚滚"的角色
- **仓鼠 / 团子鼠**（塞满腮帮，圆到极致）
- **团子熊 / 北极熊 / 棕熊**（圆团 + 小圆耳）
- **河豚 / 圆咕噜的鱼**（鼓起来的圆云）
- **小鸡 / 小鸭**（圆身 + 一个小尖嘴）
- **刺猬 / 松鼠**（圆身，松鼠可加一个尾巴方向）

### C. 竖高形的云 → 适合"站着/坐着"的角色
- **企鹅**（竖云 + 正脸，稳赢）
- **小熊坐姿 / 抱抱姿势**
- **兔子**（竖高 + 云顶有两个凸起当耳朵）
- **小狗坐姿（柴犬 / 泰迪 / 萨摩耶）**
- **考拉 / 树懒**（竖抱姿态）

### D. 带明显凸起 / 尖角的云 → 顺着凸起做特征
- **兔子**（凸起 = 耳朵）
- **狐狸 / 柴犬**（尖耳 + 尖嘴）
- **小鹿**（凸起 = 鹿角雏形，点到为止）
- **小鸟 / 鹦鹉**（一撮翘起的云 = 呆毛/冠羽）

### E. 网络最出圈的"表情包脸"（云够正就用）
- **柴犬**（微笑脸、doge）
- **水豚**（无所谓脸）
- **海豹 / 小奶狗**（无辜大眼）
- **鹅 / 鸭**（憨憨侧脸）
- **青蛙**（大眼 + 阔嘴，云偏圆扁时）

## 三、角度菜单（顺着云的朝向选）
- **正脸**：云是团块正对你时——最亲切、最治愈。
- **3/4 侧脸**：云有明显朝向时——最自然、最有神。
- **完整侧身**：横长云——适合趴、走、躺。
- **回头 / 探头**：云一端翘起时——最俏皮。
- **背影 + 回眸**：云主体朝外、只有一小块朝你时——高级感。

## 四、姿态与动作菜单（顺着云的团块选）
趴着 · 坐着 · 打滚 · 探头张望 · 抱着东西 · 招手 · 打哈欠 · 睡着 · 抬头看 · 偷看 · 伸懒腰
> 动作只靠"表情 + 现有云块的走向"来暗示，**不新增云没有的四肢去摆动作**。

## 五、情绪菜单
呆萌（默认）· 治愈 · 松弛/无所谓 · 微微好奇 · 困倦 · 害羞（加腮红）· 小得意
> 避免：过度兴奋、夸张搞怪、过甜腻、低幼。

## 六、多角色：一朵云不止一个灵魂

当云本身就分成几团、或有明显的主次团块时，可以顺势点出**多个角色**——这往往比单角色更有故事感、更出片。

**什么时候适合多角色：**
- 云天然分成 2–3 个独立团块（各自能当一个头/身体）。
- 有明显的"一大一小"结构 → 亲子（猫妈妈带小猫、大熊抱小熊）。
- 两团并排大小相近 → 朋友 / 情侣 / 一对（并排探头、对望）。
- 一大团 + 几个小碎云 → 主角 + 跟班 / 一窝小的。

**铁律（和单角色完全一致）：**
- 有**几个真实团块**才做**几只**角色，**不把一整团云硬拆成好几只**。
- 每只角色只用它**自己那块云已有的形状**，绝不为了凑成一家人而在天空里补画身体、四肢或多余的云。
- 角色之间可以有轻微的关系暗示（对望、挨着、一个探头看另一个），但只靠**表情和已有云块的朝向**表达，不加连线、不加道具堆砌。
- 数量克制：默认 1 只，2 只是甜点，3 只封顶；宁可少，不要满。
- 多角色时**画风要统一**（同一线条粗细、同一审美区间），但每只顺着各自云形自然生长，不必长得一模一样。

## 七、最重要的一句话
**云决定了它能是谁。你的工作是从这份库里，认出它本来就想成为的那一个，然后只用最少、最美的几笔，把它请出来。**
