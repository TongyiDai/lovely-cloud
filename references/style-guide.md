# 可爱的云 · 风格指南 (Lovely Cloud Style Guide)

## 一、风格定义
Cloud Spirit 的核心不是“把云画成卡通”，而是“从云里认出灵气”。

最终效果要满足 4 个词：
- 真实
- 克制
- 有神
- 可亲近

## 二、视觉语言
### 1. 真实底图优先
原始照片的天空和云，是第一主角。
所有涂鸦只是附着在真实云上的轻量表达。

### 2. 轻量涂鸦
应使用简洁的手绘笔触去点出：
- 眼睛
- 嘴巴
- 耳朵或局部轮廓
- 极少量装饰元素

### 3. 留白
让观者自己脑补，是这个风格最关键的来源之一。
不要把答案写满。

## 三、角色判断法
### 适合完整补形的情况
- 云团明显像兔子、猫、熊、鸡、鱼、人脸
- 云形有天然耳朵、头部、尾巴、身体方向
- 补 3–10 笔就能成立

### 适合只补表情的情况
- 云只是蓬松、团状、层叠
- 一旦补太多就显得刻意
- 原图氛围本身已经很好

## 四、装饰使用规则
装饰元素只起到“轻点一下”的作用。
推荐排序如下：

1. 白色短线
2. 小爱心
3. 小帽子
4. 眼镜
5. 小胡子

规则：
- 每张图最多一种核心装饰
- 若云层本身已经足够有趣，则不加装饰

## 五、色彩规则
### 主色
- 黑色：轮廓线
- 白色：眼睛 / 小光点
- 红色：嘴巴 / 爱心 / 腮红少量使用

### 注意
不要引入大面积新颜色。
不要改变照片本来的蓝天、晚霞、阴天氛围。

## 六、失败案例识别
以下情况说明做坏了：

### 1. 太像贴纸
问题：轮廓太完整、太平滑、太规整。
修正：减少轮廓闭合度，增加轻微手绘感。

### 2. 太像儿童插画
问题：元素太满、太甜、太密。
修正：删掉一半以上装饰。

### 3. 太像重新作画
问题：天空被改动太多，失去照片感。
修正：重新以“照片编辑”思路处理，不要重画背景。

### 4. 太硬凹角色
问题：云根本不像，却非要做成某种动物。
修正：回退到轻表情模式。

## 七、推荐默认档位
当用户没有任何说明时：

- 风格强度：轻—中之间
- 气质方向：治愈 + 呆萌
- 拟物程度：半角色
- 装饰：无或极少
- 留白：高

## 八、批量一致性规则
如果用户一次上传多张云图：
- 画风应统一
- 笔触粗细应统一
- 情绪应保持同一审美区间
- 角色不必完全统一
- 每张图依然应顺着各自云形自然生长

## 九、最重要的一句话
**不要创造一个角色贴到云上。要从云里，把角色请出来。**
