# 一朵小可爱 · 风格指南 (Lovely Cloud Style Guide)

## 一、风格定义
Cloud Spirit 的核心不是“把云画成卡通”，而是“从云里认出灵气”。

最终效果要满足 4 个词：
- 真实
- 克制
- 有神
- 可亲近

## 二、视觉语言
### 1. 真实底图优先
原始照片的天空和云，是第一主角。
所有涂鸦只是附着在真实云上的轻量表达。

### 2. 轻量涂鸦
应使用简洁的手绘笔触去点出：
- 眼睛
- 嘴巴
- 耳朵或局部轮廓
- 极少量装饰元素

### 3. 留白
让观者自己脑补，是这个风格最关键的来源之一。
不要把答案写满。

## 三、角色判断法
> 底线：充分利用云的**全部真实细节**——外形、内部团块、凸起、褶皱、明暗、体积——去塑造角色，让它有立体感、有神采。是在云里把角色"请出来"，不是只沿外缘描一圈。唯一禁区：不在完全空白、没有云的天空里凭空捏造毫无依据的部件。

### 适合塑造较完整角色的情况
- 云团本身已经明显像兔子、猫、熊、鸡、鱼、人脸
- 云有多个团块或明暗层次，可分别用作头、身体、四肢
- 顺着已有的团块和明暗，就能自然长出一个立体的角色

### 适合只补表情的情况
- 云只是单一团块、蓬松、没有明显结构
- 一旦硬加空白处没有的部件就显得刻意、像凭空造形
- 原图氛围本身已经很好

## 四、装饰使用规则
装饰元素只起到“轻点一下”的作用。
推荐排序如下：

1. 白色短线
2. 小爱心
3. 小帽子
4. 眼镜
5. 小胡子

规则：
- 每张图最多一种核心装饰
- 若云层本身已经足够有趣，则不加装饰

## 五、色彩规则
### 主色
- 黑色：轮廓线
- 白色：眼睛 / 小光点
- 红色：嘴巴 / 爱心 / 腮红少量使用

### 注意
不要引入大面积新颜色。
不要改变照片本来的蓝天、晚霞、阴天氛围。

## 六、失败案例识别
以下情况说明做坏了：

### 1. 太像贴纸
问题：轮廓太完整、太平滑、太规整。
修正：减少轮廓闭合度，增加轻微手绘感。

### 2. 太像儿童插画
问题：元素太满、太甜、太密。
修正：删掉一半以上装饰。

### 3. 太像重新作画
问题：天空被改动太多，失去照片感。
修正：重新以“照片编辑”思路处理，不要重画背景。

### 4. 太硬凹角色
问题：云根本不像，却非要做成某种动物。
修正：回退到轻表情模式。

### 5. 只描外缘，像一滩东西（最常见的失败）
问题：只沿着云的外轮廓勾了一圈，没用云内部的团块、褶皱和明暗，角色扁平、呆板、没有立体感和细节，像给一摊棉花描了个边。
修正：充分利用云内部的结构——把不同团块用作头/身体/四肢，用明暗和褶皱做出体积感和毛发感，让角色真正"长"在云里、有神采。

### 6. 无中生有（造云）
问题：在完全空白、没有云的天空里凭空画出毫无依据的部件，硬拼出一个角色。
修正：删掉那些天空里没有云支撑的部分；角色的每一处都要有云的真实结构作依据。注意：用云内部已有的细节做身体四肢，不算造云，是鼓励的。

## 七、推荐默认档位
当用户没有任何说明时：

- 风格强度：轻—中之间
- 气质方向：治愈 + 呆萌
- 拟物程度：半角色
- 装饰：无或极少
- 留白：高

## 八、批量一致性规则
如果用户一次上传多张云图：
- 画风应统一
- 笔触粗细应统一
- 情绪应保持同一审美区间
- 角色不必完全统一
- 每张图依然应顺着各自云形自然生长

## 九、最重要的一句话
**不要创造一个角色贴到云上。要从云里，把角色请出来。**
